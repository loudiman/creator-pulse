## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| working tree → git history | Any file not matched by an ignore rule can be committed, and an un-commit is a rotation, not a fix |
| gate result → phase closure | Every later phase is judged by these four commands; a weakened gate reports green while meaning nothing |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-09 | Information disclosure | A secret path reaching git history via a missing ignore rule | high | mitigate | `git check-ignore -q` assertions run against git itself for the env file, the SQLite database, the venv and the research cache — behavioural, not textual. `! git status --porcelain \| grep -q '^??'` proves no artifact is trackable after a full install and gate run. The existing rules are appended to, never rewritten, so no established protection can be dropped by accident. |
| T-01-10 | Repudiation | A weakened gate reporting green | medium | mitigate | This plan's prohibition forbids loosening a rule, suppressing a finding, or relaxing an assertion to reach green. Two acceptance criteria enforce it mechanically: a negative grep for suppression comments under `src/`, and an empty `git diff` over `tests/` for this task. |
| T-01-11 | Tampering | An overwrite of the already-committed `.gitignore` | medium | mitigate | A precondition asserts the file is tracked before editing, the action instructs append-only under a new heading, and an acceptance criterion requires `git diff .gitignore` to show no deletions or reordering. |
| T-01-12 | Spoofing | A README install step that silently selects the wrong interpreter | low | mitigate | The README pins the interpreter explicitly per platform, because bare `python` on the development box resolves to the Store alias stub and bare `py` resolves to a newer interpreter than the VPS runs. `requires-python` is bounded so a mismatched venv fails loudly at install rather than diverging at runtime. |
</threat_model>
