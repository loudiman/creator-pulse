    Add a private helper that resolves the service account address out of the key file. It takes
    the key-file `Path`, returns `str | None`, and reads exactly one field — `client_email` — via
    `json.loads(path.read_text(encoding="utf-8"))` followed by a `.get`. It returns `None` on
    `OSError`, on `json.JSONDecodeError`, and when the parsed payload is not a mapping. It never
    reaches for any other field in that JSON, and it never returns or logs the file's contents;
    `client_email` is a public address, everything else in that file is credential material.

    Guard the client construction in its **own** try block, separate from the `open_by_key` block.
    Catch `OSError` and `json.JSONDecodeError` there and raise `SheetsKeyfileUnusable` naming the
    resolved key-file path and the env var `CREATORPULSE_SHEETS_KEYFILE`, chained with
    `from exc`. **The two blocks must not be merged:** `PermissionError` is a subclass of
    `OSError`, so a single combined try would report an unshared Sheet as a key-file problem —
    the exact misdiagnosis SHEET-07 exists to prevent.

    Wrap `open_by_key` with three except arms, in this order and no other:
    1. `except PermissionError` — the verified primary case, a bare builtin with no message.
       Raise `SheetNotShared` saying the Sheet is not shared with the resolved address and to
       share it with that address as Editor. When the helper returned `None`, fall back to a
       message that names the key-file path and says the address could not be read from it — the
       operator still has somewhere to go.
    2. `except gspread.exceptions.SpreadsheetNotFound` — raise `SheetNotShared` saying the id was
       not found, naming `CREATORPULSE_SHEET_ID`, and noting a deleted Sheet reads the same way.
    3. `except gspread.exceptions.APIError` — re-raise as `SheetNotShared` only when the response
       status is 403; on any other status re-raise the original exception untouched, so a 500 or
       a 429 stays a transient API failure rather than being relabelled a permission problem.
    The import path is `gspread.exceptions.APIError` — the top-level alias does not exist.

    Wrap the single `Worksheet.update` call from `04-02` in one `except gspread.exceptions.APIError`
    arm. On status 403 raise `SheetNotShared` with a distinct message: the Sheet opened for
    reading but the write was refused, so the share is Viewer and needs to be Editor. Any other
    status re-raises unchanged. This arm is not optional — a preflight on `open_by_key` alone
    cannot see the Viewer case, because reading is exactly what Viewer permits. Leave the
    `A1:F{n+1}` range and the `ValueInputOption.user_entered` argument exactly as `04-02` set them.

    Do not add a retry, a sleep, or a backoff around either call site.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process → journald | exception messages and log lines from a failed sync become durable, readable-by-operator text |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
