## Verified gspread 6.2.1 facts (checked this session against the installed package — do not re-derive)

These four are the difference between a green gate and an afternoon of debugging. Every one was
confirmed against `.venv` at gspread 6.2.1, and the exact module shape in this plan was run through
`mypy --strict`, `ruff check`, and `ruff format --check` before the plan was written.

1. **`Worksheet.update` takes values FIRST.** The signature is
   `update(values, range_name=None, *, value_input_option=None, ...)`. gspread 5.x's
   `update(range_name, values)` order is **wrong** on 6.x. Write `worksheet.update(values,
   range_name, value_input_option=...)`.
2. **`value_input_option` will not accept a plain string under mypy strict.** gspread ships
   `py.typed`, so the parameter is typed `ValueInputOption | None` and passing the bare string fails
   with `Argument "value_input_option" ... has incompatible type "str"`. Import
   `from gspread.utils import ValueInputOption` and pass `ValueInputOption.user_entered`. It is a
   `StrEnum` member equal to the wire value, so PITFALLS.md §5 and D-04 are satisfied literally.
3. **`open_by_key` is NOT lazy — it makes a real HTTP GET.** `Spreadsheet.__init__` calls
   `fetch_sheet_metadata()` in its own body, so the permission failure surfaces at `open_by_key`,
   which is what makes D-08's preflight-at-`open_by_key` the correct call site in 04-03.
4. **An unshared Sheet raises a bare builtin `PermissionError`, not `APIError`.** gspread's
   `open_by_key` maps HTTP 403 to `raise PermissionError from ex` **with no message at all**, and 404
   to `SpreadsheetNotFound`. D-08's wording names `APIError` / `SpreadsheetNotFound` and therefore
   **misses the primary unshared case.** 04-03 must catch `PermissionError` first — it is the
   PITFALLS.md §3 "100% of the time on first run" failure. Recorded here because 04-01 is where the
   call site is created; 04-01 does not implement the handler (SHEET-07 is 04-03's requirement).

Two further notes: `gspread.exceptions.APIError` is **not** re-exported at `gspread.APIError`, so
04-03 imports from `gspread.exceptions`. And `Spreadsheet.worksheet(title)` raises
`WorksheetNotFound` naming the title — that message is already actionable, so this plan lets it
propagate rather than wrapping it, and creating the tab is a `user_setup` item.
