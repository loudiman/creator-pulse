## Phase Goal

**The ops team gets a Sheet they can actually read** (`ROADMAP.md` §"Phase 4").

*Note on MVP framing:* the ROADMAP Goal line is a plain outcome sentence, not the canonical
**As a** / **I want to** / **so that** form. It is carried through verbatim rather than invented
into a story here — if a formal user story is wanted, `/gsd mvp-phase 4` is the command that
writes one, and it is not this plan's to fabricate.

<objective>
Produce the two documents Phase 4 owes and no code at all.

1. **`COVERAGE.md`** — the Google Sheets API v4 capability matrix, in the house style Phase 3 set.
   Phase 4 integrates an external API (Google Sheets v4, through gspread 6.2.1, authenticated by a
   service account), so a coverage matrix is mandatory and this plan owns it. `INTEGRATE` is the
   default; the file is therefore a **subtraction record** — it exists to show that `append_rows`,
   `.clear()`, cell-by-cell writes, every read-back path, and the whole Drive-scoped half of gspread
   were each *decided against with a reason*, not merely never reached for.

2. **`04-UAT.md`** — the human-verification scaffold, following `02-UAT.md` / `03-UAT.md` exactly:
   pasted command output per criterion, no screenshots, because pasted output is greppable,
   diffable, and re-checkable a week later. Four entries, matching the four ROADMAP criteria that
   survive the 2026-08-05 cut of SRC-03 and SHEET-04. All four ship `pending` with the commands
   that will close them, because no Google service account exists yet.

Purpose: the matrix closes the "nobody decided" hole before the phase seals, and the scaffold turns
the manual verification gate (`ROADMAP.md` §"Definition of Green" — human-observed real data
reaching the real Sheet, from Phase 3 onward) from a memory into a checklist.

Output: two files under `.planning/phases/04-playwright-sheets/`. Zero source files.

**Scope boundary, stated once:** SRC-03 (TikTok/Playwright) and SHEET-04 (History tab) are CUT.
This plan plans no code change, and specifically does **not** remove Playwright from
`pyproject.toml` — a gate-touching dependency removal with no benefit, explicitly deferred in
`04-CONTEXT.md` §Deferred Ideas.
</objective>
