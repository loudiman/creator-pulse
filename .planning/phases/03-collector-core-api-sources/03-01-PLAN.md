Add a repeatable `--header` argument to the recorder so it can reach an endpoint that requires
`Authorization` and `Client-Id`. Twitch Helix rejects an unauthenticated request, so without this the
five Twitch fixtures cannot be produced by the sanctioned path at all — and hand-authoring them is
forbidden. Those five recordings are deferred on a missing credential (see `## Deferred`), and the
flag is still built and gated today for exactly that reason: it is the thing that makes them
recordable the moment a client id exists, and it costs nothing to have waiting.

Use `parser.add_argument("--header", action="append", default=None, metavar="'Name: value'")`,
producing `list[str] | None`. Parse each entry by splitting on the first colon only, so a value
containing a colon survives intact. Strip surrounding whitespace from the name and from the value.

Validate every entry **before** any request is made, in the same loop position and the same style as
the existing `--source`/`--case` guard: an entry with no colon, or an empty name after stripping, or
a name containing whitespace, prints `invalid --header: <repr>` to stderr and returns exit code `2`.
This mirrors line 30-33's shape exactly — the point of that guard is that a malformed argument costs
nothing and reaches nothing, and the new flag must not be the one argument that fails late.

Pass the assembled dict as `requests.get(args.url, headers=headers, timeout=_TIMEOUT_SECONDS)`. When
the flag is absent, pass no `headers` keyword at all rather than an empty dict, so the existing
call shape and the existing YouTube recordings are byte-identical to before.

Do not touch the path-containment check, the slug regexes, or `response.raise_for_status()` — those
three are why a challenge page can never masquerade as a fixture, and this change must leave all
three exactly where they are. Do not add a `--method` flag: nothing in this phase needs the recorder
to POST, and the one POST in the project (the OAuth mint) must never have its response body saved.

Extend the module docstring's first line to mention headers, keeping its existing shape and keeping
