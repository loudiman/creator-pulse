<objective>
Deliver the tracer slice for Phase 2: a `creatorpulse collect` run announces, in its first log line,
which config file and which database file it actually used — resolved to absolute paths, sourced from
`CREATORPULSE_CONFIG` and `CREATORPULSE_DB` when systemd sets them (D-06, D-07) and from the existing
repo-relative defaults when nothing does (D-08). Then produce the two committed artifacts the author
needs on hand before touching a droplet: `.env.example` (D-14) and the `02-UAT.md` proof scaffold (D-15).

Purpose: ROADMAP success criterion 2 requires `systemctl start` to succeed "against the same code path
that works interactively." That claim is vacuous unless one function resolves paths identically in both
situations, and unless the run says out loud which paths it picked. This plan is where that function is
written and proven end-to-end on the dev box, before the box the unit runs on exists.

Output: `resolve_paths()` in `config.py`, a `db_path` threaded through `cli.py` and logged, three tests,
`.env.example`, and `02-UAT.md`.

`deploy/creatorpulse.service`, `deploy/creatorpulse.timer`, and `docs/deploy.md` are human-built. Do not

commit message, not in the SUMMARY.
